BIBLIOTECA DIGITAL:

Este es un sistema de gestión de biblioteca digital desarrollado con CustomTkinter y Python. 
El proyecto permite realizar préstamos de libros, administrar el catálogo, y gestionar las devoluciones, todo a través de una interfaz gráfica interactiva.


REQUISITOS:
Antes de ejecutar el programa, asegúrate de tener instaladas las siguientes dependencias:
  1. Python 3.x (preferiblemente 3.8 o superior)
  2. Pillow (para manipular imágenes en la interfaz gráfica)
  3. CustomTkinter (para crear la interfaz de usuario)
