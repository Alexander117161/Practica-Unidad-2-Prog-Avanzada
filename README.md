BIBLIOTECA DIGITAL:

Este es un sistema de gestión de biblioteca digital desarrollado con CustomTkinter y Python. 
El proyecto permite realizar préstamos de libros, administrar el catálogo, y gestionar las devoluciones, todo a través de una interfaz gráfica interactiva.


REQUISITOS:
Antes de ejecutar el programa, asegúrate de tener instaladas las siguientes dependencias:
  1. Python 3.x (preferiblemente 3.8 o superior)
  2. Pillow (para manipular imágenes en la interfaz gráfica)
  3. CustomTkinter (para crear la interfaz de usuario)


INSTALACIÓN:
  1. Clona el repositorio o descarga el proyecto en tu máquina local.
  2. Organiza las carpetas:
     
     Práctica Unidad 2 Prog Avanzada/
  main.py
  vistas/
      inicio_view.py
      busqueda_view.py
      prestamo_view.py
      administracion_view.py
  controladores/
      controlador.py
  modelos/
      libro.py
      prestamo.py
  data/
      libros.json
     
4. Asegúrate de tener el archivo de datos libros.json dentro de la carpeta data/, que es donde se almacenarán los libros de la biblioteca.


EJECUCIÓN:
Para ejecutar el programa, simplemente abre una terminal en la carpeta donde se encuentra el archivo main.py y ejecuta el siguiente comando: python main.py
o 
Desde VSCode abra los archivos py y ejecute main.py

El programa se iniciará y podrás interactuar con la interfaz gráfica.
